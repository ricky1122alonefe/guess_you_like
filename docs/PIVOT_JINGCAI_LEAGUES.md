> **一句话**：分析对象 = **竞彩足球当前/近期开售场对应的联赛与对阵**，不再以世界杯专题为主叙事。  
> **仓**：`guess_you_like` only  
> **配合**：`docs/QUEUE_ALL_IN_ONE.md`、`docs/CODEBUDDY_MARKET_FORM_EV.md`  
> **日期**：2026-08-11  

---

## 1. 新旧对比

| 维度 | 旧（世界杯向） | 新（竞彩联赛向） |
|------|----------------|------------------|
| 主数据域 | 世界杯窗口、小组/淘汰专题 | **竞彩 jczq 开售列表 + 同窗口 500 盘口** |

## 2. 「竞彩开的联赛」定义（写死）

**纳入主分析队列的场次**，满足其一即可：

1. `trade.500` / jczq 元数据有 **match_num**（如 `周一001`），或  
2. poll 的 jingcai 快照 `has_sp` / 有 spf|rqspf，或  
3. 配置白名单联赛名（500 展示名）且 kickoff 在 poll 窗口内——**仅作补充，优先 1+2**

**不进主列表默认视图**（可「显示全部 500」开关）：

- 仅 live.500 有、无任何竞彩编号的长尾友谊赛/小联赛  

**世界杯场**：若当期竞彩也开，则 **当普通竞彩场** 处理，不走独立世界杯产品链路。

## 3. 必须改的代码点（实现清单）

### D1 列表与 poll 默认过滤
- 首页 `load_dashboard_matches` / daily：默认 **`has_jingcai` 优先**（编号或 SP）  
- poll 仍可抓全联赛盘口（为欧亚），但 **UI 默认只亮竞彩在售**  
- 配置：`FOCUS_JINGCAI_ONLY=1`（默认 true）

### D2 战绩引擎对齐联赛
- `club_form`（Q1-P2）按 **500 league_name → football-data 联赛码** 映射表  
- 建 `config/jingcai_league_map.yaml`：常见竞彩联赛（英超、西甲、意甲、德甲、法甲、荷甲、葡超、苏超、日职、韩 K、美职、澳超、北欧、南美解放者等 **按你们实际 jczq 出现补**）  
- 废弃当主路径：仅 WC 的 `team_recent_form` + WorldCup2026.xlsx  

### D3 队名
- 中文 500 名 → canonical 英文/历史库名（别名表可维护）  
- 匹配失败：战绩 missing，盘口分析仍可用  

### D4 导航与文案
- 首页标题/README：**竞彩开售联赛盘口**，去掉世界杯主标题  
- `/worldcup*` 全部归 「更多 · 历史专题」  
- AI prompt 默认 `profile=league`，不要默认 `worldcup`  

### D5 规则/预测
- result_forecast / 串关 EV 数据源：**该场欧亚必发 + 联赛战绩**，不依赖「是否世界杯」  
- 竞彩 SP：可购与串关结算赔率优先；无 SP 仍用欧赔算分析 EV/赔率腿  

### D6 复盘
- settle / review 按竞彩日或自然日，不按世界杯轮次
